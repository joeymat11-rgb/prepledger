Measured — the NOW page, decluttered

Design pass · 3 directions to react to · not built, not shipped. Same design system, charter (calm / no streaks / no urgency) and engine-owns-numbers. Every number shown is illustrative of a real engine output.
TIER 0 — the cockpit. Auto-Pilot status word + today's ONE action. The eye lands here first, every morning.
TIER 1 — glanceable. The five levers + the measured trajectory / FORESIGHT. Visible, but never competes with Tier 0.
TIER 2 — one tap down. Capture surfaces, the analyst read, the room. Nothing deleted — everything is one labelled tap away, in the same place every day.
