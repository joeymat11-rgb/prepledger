# Earned — where to run the server authority, the database, and sign-in

Decision packet, 2026-09-04. All prices/limits below were read from the linked pages today; they change often. Where a page would not load, it says so.

## What the backend has to do (plain English)
One small server program that: checks each phone's signed operation (HMAC), gives it the next sequence number in that athlete's log, writes it to an **append-only** table, signs a receipt and a 30-day offline lease with a **private key that only the server knows**, and runs a small deterministic "policy" step. Plus: sign-in, a scheduled sweep (expired leases), and backups. Health data must be readable only by its own athlete.

## Things that would bite you (the non-obvious ones)
- **Supabase Free pauses after 1 week without traffic** [1]. On a two-person beta a quiet holiday week is realistic; the app then errors until you log in and click Restore. Free also has **no automatic backups** [11]. Both go away on Pro ($25/mo). Built-in sign-in email is capped at **2 emails/hour** unless you connect your own mail sender (https://supabase.com/docs/guides/auth/rate-limits).
- **Firebase's "free" plan cannot run server code**: deploying functions requires Blaze [3], i.e. a billing account. Standard Firebase Auth (email/social) has no MAU cap or charge on either plan [2]. Cloud Scheduler: 3 jobs free, then $0.10/job/mo (https://cloud.google.com/scheduler/pricing).
- **Netlify's new credit model punishes frequent deploys**: 300 free credits, 15 per production deploy [7] — 20 deploys and the month is spent, and "projects pause until the next billing cycle" [8]. An AI agent that ships small changes daily will hit this. Netlify Identity is still offered on credit-based plans at no extra cost (https://docs.netlify.com/manage/security/secure-access-to-sites/identity/overview/). Neon's Managed Auth is in **Beta** (https://neon.com/docs/guides/neon-auth).
- **Cloudflare has no consumer sign-in product.** Cloudflare Access is for staff (a third-party site reports 50 free users then $7/user/mo — https://costbench.com/software/business-vpn/cloudflare-zero-trust/free-plan/ — Cloudflare's own pricing page would not render the numbers). For athletes you would use **Clerk** (free tier "50,000 MRU per app", Pro $25/mo monthly-billed, https://clerk.com/pricing) or an open-source auth library (Better Auth's Cloudflare page returned 404 today, so unverified). Free Workers get 10 ms CPU per request [5] — enough for HMAC and a small reduction, but Paid raises it to 30 s default [5].
- **Fly.io is the cheapest metal but the most ops.** No free tier, card required [10]. Fly's own LiteFS page says "We are not able to provide support or guidance for this product" (https://fly.io/docs/litefs/), which is why Litestream, not LiteFS, is the pairing here. One machine = downtime on every restart; restores are a manual command.
- Data-residency: Firebase [15] and D1 [16] lock the location at creation. Decide region first, everywhere.

## What I would pick and why
**Pick: (c) Cloudflare Workers + D1 on the $5/mo Paid plan, with Clerk (free tier) for sign-in.**
- Cheapest real plan ($5/mo) with the best default safety: backups are automatic and always on (30-day point-in-time restore) [12], nothing pauses for inactivity, and the database is only reachable from your own Worker code — "private from day one" is the default, not a setting to get right.
- The architecture is a single-writer append-only log with server-side signing. D1 is exactly that shape; the signing key sits in a Worker secret that is hidden once set [20]. Cron Triggers cover the lease sweep [5].
- Lowest lock-in of the managed options: D1 exports to a plain SQLite file; the Worker is ordinary JavaScript.
- Cost of this choice: sign-in is a second vendor (Clerk) holding athletes' emails (not their health data), and Clerk's free tier shows Clerk branding. Honest uncertainty: I could not verify the open-source auth alternative today, and the 10 ms free-tier CPU cap is why I say pay the $5 from day one.

**Runner-up: (a) Supabase Pro ($25/mo).** Everything (Postgres, sign-in, functions, cron, dashboard) in one friendly place with one bill; best pick if you value "one account, one dashboard" over $20/mo. Reasons it is not first: free tier pauses and has no backups, Pro is 5x the price, and Supabase exposes tables through a public API by default, so per-athlete privacy depends on row-level-security rules being written correctly (Claude Code can, but it is a foot-gun that (c) does not have).

Not recommended: (b) — highest lock-in and the free plan cannot run the authority; (d) — deploy credits and two vendors; (e) — you would be the sysadmin.

## Three questions you must answer before committing
1. **Region.** Where should the data live (US, EU, other)? Firebase and D1 lock it at creation; pick once.
2. **Budget ceiling.** Is $5/mo (pick) or $25/mo (runner-up) the number? Say a hard cap; both platforms can be capped/alerted but only if we set it.
3. **Deploy token for the AI agent.** Are you willing to create an API token for Claude Code so it can deploy the Worker, create the database, and set the signing-key secret without you clicking through dashboards? (Yes = minimal ops for you; No = you run each deploy command yourself.)
