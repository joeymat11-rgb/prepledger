3. Implement W3/W4 against synthetic data. D1 reads the athlete's rows plus ownership/dependency inputs in one read batch with a database revision; run the synchronous authority against a staged cache; an atomic write batch first asserts that revision through a failing SQL constraint, then appends all effects and advances it. 4. The browser bridge awaits IndexedDB load, signature work and one durable transaction covering operations, outbox, sequences, leases/high-water, dispositions/rejections and checkpoint. Run the synchronous client against an isolated candidate snapshot; publish its model and acknowledge only after `IDBTransaction.complete`; abort discards the candidate. A revision check inside that same transaction serializes tab/PWA writers. Merely returning a Promise from `backend.commit()` would acknowledge early in the current `store.cjs` and is forbidden.
W4 maps explicit Clerk sign-out intent, authenticated device revocation/account closure, and unavailable local decryption or recovery to state 17 as soon as known; it takes precedence over expiry-only state 11 even with a valid lease. Mere session expiry on a still-enrolled, locally decryptable device pauses sync but permits leased logging; an unavailable SDK/network response alone does not prove sign-out or revocation. ## 4. Risks ranked with concrete mitigation

1. **Silent local loss or impossible clock continuity.** Full store eviction can erase the existing checkpoint too; absence must enter state 18 until authenticated enrollment proves first use, never infer first use from an empty database. Persist authenticated high-water with each write; after unprovable reboot/restore continuity enter state 20. Exercise C1/C11 together early: inability to meet both is a D1 failure, not permission to trust wall time. Storage persistence requests are evidence to record, not a guarantee; [WebKit documents quota and eviction](https://webkit.org/blog/14403/updates-to-storage-policy/).
2. **D1 read/write race or false local Saved.** Use the guarded staged bridges above, crash every boundary and run concurrent sessions through two separate Worker invocations. Include waiting-child drain and foreign ownership changes in the revision. A successful batch alone does not protect earlier reads; an in-memory lock does not serialize different Worker isolates.
3. **Private data or signing power crosses accounts.** Derive athlete scope from verified Clerk subject plus enrolled device, never request IDs. Parameterize every query; deny unknown origins; no athlete response caching. Use payload encryption and secret-only signing, separate backup custody, schema-limited telemetry and two-account negative tests across every endpoint. Clerk is sign-in, not authorization or recovery of encryption keys.
4. **A restore/rollback erases legitimate later writes.** Restore only into a separate database and isolated logical account/environment, preserving the original opaque athlete identity and signed bytes. Compare at W, then replay later operations before activation. Time Travel overwrites a database in place; it is not an isolated-account clone. [Time Travel](https://developers.cloudflare.com/d1/reference/time-travel/)
5. **The ruled $5 cap or US residency is falsely claimed.** Provider alerts do not stop spend; CPU/admission limits reduce exposure but billed rejected requests remain possible. D1 `enam` is not a US guarantee. Keep the chosen stack; require an explicit owner resolution before real-data deployment instead of silently replacing the rulings. Sources and resolution paths are in §8.
6. **A green core suite masks a broken port or unsupported promise.** Pin M2's complete census and second-gate evidence, require the real transport/storage rigs, independently execute the reviewer objections, and keep §C PENDING items visible. New device/OS support or a changed storage implementation requires fresh relevant evidence, including a restarted soak when survival assumptions change.
7. **One machine/person is the recovery path.** Store nonsecret commands and inventories in the repo; keep encrypted backups and recovery material outside it under named custodians. A nominated backup integrator must complete HANDOFF without the primary operator, using independently provisioned scoped credentials.
