## Durable public client contract

`createDurablePublicClient({repository,stage,namespace,athleteId,deviceId,sessionEpoch,isCurrentSession,observationEpoch,observationGuard,validateCommit,keys,subtle?,crypto?,monotonicMs?,maxTimeRoundTripMs?,schemaVersion=1,permissionNowIso?})` owns the W5 public boundary and internal sinks. Build `stage` with `createT2Stage(configProvider,{allowInbound:true})`; the public factory supplies verified integration configuration. It never provides a dummy HMAC authority key or exposes its structural grants/sinks.
The host must supply trusted `observationGuard.run(kind,action)` and a final validator. **No production implementation of the knowledge fence is supplied here.** Tests use explicitly synthetic guards; injecting one is not evidence of safe production observation, sign-out, persistence failure or B11 availability.

| Method/result | Contract |
|---|---|
| `execute(command,args)` | Actual local T2 candidate; success acknowledgement/Saved only after IDB complete and current session/observation check. Failed write retains input; no new durable operation or sequence. |
| `current()` / `reopen()` | Clone published view; session changes hide prior-account truth immediately, without another command. Known17/18/19 hides truth. Missing/corrupt inner or outer storage refuses18. |
| `acceptResponse(kind,{wireVersion,body},expectedWatermark?)` | Version `earned/w5-http/v1`; kind disposition/pull/snapshot/lease. Disposition uses `body.disposition`, lease uses `body.lease`; pull/snapshot use the signed body. W5 verifies before internal durable sinks. Normal inbound success requires `accepted:true` and `result:{stored:true,durable:true,...}`. |
| Ordinary durable refusal | `{stored:false,durable:false,state,code,reason}` with bounded nonprivate reason; W5 response normalization exposes the underlying17/18/19/20 instead of unexplained12. T2 receipt numeric0 is success; T2 storage throws are caught. |
| Completed disk, changed context before delivery | Preserve true disk facts: `{stored:true,durable:true,confirmed:false,committed:true,committedRevision,state,code,reason}`. Local result has `acknowledged:false`; inbound result has `accepted:false`. **stored:true alone never permits painting or Saved.** This is presentation refusal, not a rollback assertion. |

Grants compare canonical structural bytes including signatures, scope and session epoch; identical clones and repeated lease predicates work during one candidate. Outcome retires the grant; CAS retry creates a fresh grant after reverification. Current session and observation epoch are checked at staging, final validation and completion delivery.
Complete original signed proofs remain in metadata and are reverified in later candidates/key contexts. Pull/snapshot receipts are individually verified. A W5 snapshot is accepted history; it is ingested through actual T2 receipts, never passed as if it were T2's unrelated projected snapshot shape. W7's engine/history projection remains separate. ## Reproduction and evidence limits

Use Node>=22 and real dependency directories. Install in this folder with `pnpm install --ignore-workspace --frozen-lockfile --ignore-scripts` using the committed W6 lock; do not change the root lock. The local `.npmrc` explicitly sets `lockfile=true` alongside npm's `package-lock=false`: pnpm10 otherwise interprets the latter as disabling its lock.
