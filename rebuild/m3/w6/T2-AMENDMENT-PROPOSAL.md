## W5 fields now pinned, and what they do not provide

All routes are POST JSON; response wire version is `earned/w5-http/v1`. W5 publishes ES256, P-256/SHA-256, low-S, 64-byte P1363 r||s, canonical base64url and domain-separated canonical bytes; use the committed fixture exactly. `/op`, `/pull`, `/snapshot`, `/time`, `/lease` and `/enrol` have distinct signed/scope semantics. `/import` and `/restore` return typed NOT_IMPLEMENTED, never success.

`/enrol` retrieves preprovisioned enrollment; it does not supply new-device provisioning. `/lease` returns the current capability; it does not renew it. No combined history/WAITING/terminal/standing/head/lease-history reconciliation proof is available. Time is an authenticated sample, not an established `[Tlo,Thi]`: production UTC error, clock-rate/step and qualified elapsed bounds are OPEN. Therefore the contract cannot create checkpoint C, refill the adopted 24-observed-hour/64-slot allowance or earn CLOCK PASS. Those missing guarantees cannot be supplied by an adapter callback that simply returns true.
