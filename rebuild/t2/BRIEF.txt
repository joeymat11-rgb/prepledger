3. CANONICAL-v1 (what your encoder must produce — same bytes as lib/canonical.cjs, implemented independently)
--------------------------------------------------------------------------------------------------------------
  strings   → Unicode NFC, then JSON string quoting (JSON.stringify)
  numbers   → canonical decimal: 0 and -0 → "0"; no exponent (1e21 → "1000000000000000000000",
              1e-7 → "0.0000001"); no trailing zeros after the point; integers without ".0";
              non-finite → the JSON string of its name ("NaN", "Infinity") so it is encodable but never equal
              to a finite encoding
  booleans  → true | false
  null      → the literal null; undefined (absent) → the key is OMITTED. absent ≠ null ≠ value
  arrays    → "[" + items joined by "," + "]" (undefined items dropped); a declared SET field (causal_parents)
              is de-duplicated and sorted by the items' canonical encodings
  maps      → "{" + "\"key\":" + encoding, keys sorted by code point, joined by "," + "}"; quantities {value,
              unit} are maps (the unit is part of the encoding)
  commitment = hex HMAC-SHA256(K_identity, "earned/op/v1" + encode(envelope))
